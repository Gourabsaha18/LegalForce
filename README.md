# LegalForce Prototype Website

This is a fully editable frontend prototype inspired by a legal news portal.

## Features
- Responsive homepage
- Navigation menu
- News cards
- Consultancy page
- Online consultation via:
  - Chat
  - Voice Call
  - Video Call
- Login modal
- Editable HTML/CSS/JS structure

## Run
Just open `index.html` in browser.

## Structure
- assets/css → styles
- assets/js → scripts
- pages → extra pages
